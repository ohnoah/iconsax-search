# License and attribution notes

The explorer application and the icon library it displays are separate works. Before publishing this repository, add the project's chosen license as a root `LICENSE` file and keep dependency notices intact.

The currently targeted `iconsax-react` package declares the MIT license and credits Iconsax in its package README. Keep the package's license declaration in dependency metadata, link to the upstream project from the explorer's About or footer area, and avoid implying that this explorer is the official Iconsax website.

Generated catalog data should contain only facts needed to locate and search icons: exported component names, normalized tokens, categories, aliases, and repository usage. Do not copy upstream website prose or artwork into this repository unless its license is confirmed separately.
